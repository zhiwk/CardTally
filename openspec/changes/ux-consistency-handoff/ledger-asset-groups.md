# UX14 — 账本资产组、同组合并与跨账本资产流水

本文件是 design.md 的增补，属于用户2026-09-11确认的新业务范围，待实施。优先于UX13第4、5、7点的旧开关/来源账本描述，其他卡片和编辑限制保持不变。业务依据：docs/requirements/decisions/2026-09-11-ledger-asset-groups.md。

## 源码现状（非完成声明）

- DatabaseHelper.assetPoolRootId / assetScope 与 addLedgerWithAssetPool 已支持通过根账本解析共享池；LedgerManagementFragment.renderAssets 已按根分组。可以复用，不需要再做第二套数据架构。
- getRecordsByAssetId 仍带 currentLedgerId 条件，不能显示跨账本流水；getRecordsByAssetSource 也按当前账本和名称查询，不可用作跨账本身份匹配。
- DateGroupAdapter 的 textAsset 当前绑定资产名/转账路径，并未绑定记录所属账本。不要把截图右侧文字直接当成已实现账本标签。
- mergeLedgerIntoCurrent 未校验组相同；更新资产所有者后删除源账本，未重定向 ledger_shared_ledgers 引用。管理页 sources.all 连续合并不是整批原子事务，不能当成安全批处理。

## 1. 新建账本

保留UX13基本信息白卡。第二张卡标题“账本资产”，两个直接可见的单选项：“新建独立资产组”“使用现有资产组”。默认后者并明确展示主资产组；不再使用共用主资产Switch加隐藏的二级模式。选择独立组显示说明“创建一组独立资产，不复制已有资产”；创建成功前不落库，失败整体回滚，不遗留空账本或组。

选择现有组时，显示当前组摘要和48dp以上的可点击选择行，打开统一BottomSheet。列表按稳定组ID去重：主组显示“主资产组”，其他组可按“资产组 · 根账本名称”生成展示标签；辅助行显示使用该组的账本名称、资产数，空组仍可选。同名组以成员和稳定标识辅助区分，不以名称存引用、不强制用户维护组名。只允许选择整组，不提供勾选部分资产或复制余额。

卡片#FFFFFF、12dp、无描边/阴影，页面#EEEEEE、左右16dp、卡间12dp。组行minHeight56dp、正文16sp/辅助12sp、48dp点击目标、明确单选标记；长成员名称可展开/在详情完整读取，不挤压主操作。字体放大时wrap_content。编辑页整张资产卡GONE，保存不改资产关系。

## 2. 管理页同组合并

沿用按资产组分组的白色圆角卡，同组多个账本时显示可发现的“合并账本”操作（不只依赖长按/滑动）。本轮流程选择两个不同账本，再明确选择保留目标；选择不同组时阻止并说明“仅支持合并使用同一资产组的账本”。所有入口（包括旧长按和批选）与数据库均校验，不能只隐藏按钮。

确认框写清源名→目标名、记录数量、“源账本将移除，资产与余额保持不变”，提供取消/确认。涉及主账本时固定保留主账本并说明原因；不扩大删除主账本权限。

数据库以显式sourceId/targetId执行单一事务，开始时重新检查存在性、同组和保护规则。将源记录ledger_id指向目标，保留记录ID、日期、金额、分类ID/快照、备注、图片和转账两端资产ID；不走新增/删除记录余额回滚流程。源为非主池根时，安全重定向全部幸存共享引用（含未合并第三账本），不得悬挂、循环或使其他账本丢失资产访问。根身份实现可变但该组资产ID、余额、成员语义保持一致。删除源与关系更新必须同事务完成；异常回滚，重复提交不再写入。成功后才更新当前账本偏好及刷新列表，失败不提前切换当前账本。

当前多选若保留超过两本的能力，必须同组、显式目标、全批单事务；否则限制为两本并提示，不允许逐本部分成功。不是要求新增批量功能。

## 3. 账户详情流水

AssetRecordsFragment 按assetId查询所有关联记录：record.assetId == assetId 或 destinationAssetId == assetId，不用当前账本过滤、不按资产名拼接；转账记录只出现一次。不混入同组其他资产或其他组同名资产。所有日期范围均可通过分页/现有加载方式到达，不能把前三个月/200条截断当“全部”。

沿用账单日期分组、#FFFFFF外卡12dp圆角、无边框阴影，确保子行背景不会盖住外圆角；图标/行高复用账单组件、分类按ID解析。右侧金额下4dp显示所属账本名，12sp次级色、右对齐，即截图箭头位置。仅资产详情用账本元信息展示模式，其他账单/搜索页的资产名不被全局替换。转账方向保留在左侧辅助说明或可展开详情，不抢占账本标签。长账本名允许两行并随内容增高，不能省略金额；无效历史关联显示明确“未知账本”，不猜当前账本。

账本重命名后标签刷新；合并后显示归属目标账本名称，不新增旧名快照体系。按records.ledger_id批量解析名称，避免每行数据库查询。日期汇总与所展示的跨账本记录集合一致，保留转账不计收支的规则。余额继续使用该资产真实余额，不从分页流水重算。

从跨账本条目打开编辑/删除必须定位记录原所属账本与ID，不能将当前LedgerSession隐式写回记录归属；原资产管理权限保持不变，不因能查看而授予资产编辑权限。

## 4. 隔离验收

创建测试A/B/C共享组G、D独立组H，G/H各有同名但不同ID资产。验证独立空组、共享去重、主组默认、草稿恢复、创建失败无残留；A/B收支及转账在同一资产详情完整出现一次，D记录不混入，标签正确、日期统计一致。

分别测试非根合并、非主根作为源且C未参与、主账本只能保留、跨组拒绝、取消、重复提交、异常回滚及当前源账本偏好修复。合并前后全部资产ID/余额、记录总数/金额/附件/叶子分类引用一致；全局分类数不变。验证跨账本编辑未悄悄搬账本，以及账本改名/合并后标签刷新。

补320/360dp、中英、字体1/2、长名称、空组/无流水、分页超过200条与旧日期。数据库写入仅在隔离库；不在用户手机创建、合并、删除真实账本，不清数据、不卸载日常应用。不以构建成功冒充业务验收。
