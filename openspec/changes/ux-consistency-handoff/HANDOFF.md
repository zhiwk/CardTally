## 给接手模型的任务

先按根目录 AGENTS.md 阅读项目入口、任务路由、current-snapshot.md 和 DESIGN.md，然后阅读本目录 proposal.md、design.md、specs/ux-consistency/spec.md、tasks.md。

严格按 UX01—UX12 实施并检查功能；不需要看截图，也不要自行重新设计。design.md 已说明文件、问题、目标与验收条件。标为“风险”的条目先通过隔离布局测试或安全设备操作复现；未复现则记录证据，不为凑任务数修改代码。已确认问题也要复核当前源码，避免重复修复其他 agent 已做的工作。

每批改动后重新读取改动文件并跑相关测试。Android Gradle 任务必须串行。不得清除、卸载用户应用或在用户数据库写入测试记录；先检查测试实现是否读写个人数据。财务、删除、归档、编辑保存测试使用独立测试数据库/模拟对象/专用模拟器。不要发送真实 AI 请求或记录 API Key。

结果写入本目录 `implementation-report.md`，逐项列出 UX 编号、改动文件、验证命令、实际结果、未完成项；风险未复现可标“无需修改（附证据）”，不能写“已修复”。只勾选真正完成的 tasks。最后报告 APK 路径 `app/build/outputs/apk/debug/app-debug.apk` 及是否实际安装，不改产物名。

**完成实现和功能检查后停止，等待用户安排视觉复审。不要自行归档 OpenSpec 变更，不要宣布全局 UX 或最终视觉验收通过。**
