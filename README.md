# CardTally

一个基于 Material Design 风格的现代化 Android 记账应用，帮助用户轻松管理个人财务，提供直观的数据分析和优雅的用户界面。

## ✨ 功能特性

- **Material Design 风格**：采用 Google 官方设计规范，界面美观、简洁、易用
- **快速记账**：支持快速添加收支记录，支持分类、描述等详情
- **两种记账模式**：在「我的 → 记一笔模式」选择「标准模式」（页内一级分类卡片，展开后选择二级分类）或「快速模式」（页内平铺叶子分类）；两者共用常驻金额键盘及录入流程
- **转账手续费**：转账可填手续费，转出资产扣「金额 + 手续费」、转入资产加「金额」；手续费计入支出总额，账单列表显示「含手续费」
- **重复记账**：支持每日、每周、每月、每年和间隔周期，支持结束日期、启停、跨账本、支出/收入/转账及转出与转入资产
- **分类管理**：自定义收支分类，支持增删改查
- **统计分析**：按分类和时间统计收支情况
- **外观切换**：在「我的 → 外观」独立二级页的纯色背景、图片背景两张卡片中选择浅色、深色或跟随系统，默认纯色浅色，选择立即应用并持久保存；图片背景支持三种配色、添加本机图片、保留图片库供切换、恢复默认图片及调节卡片不透明度
- **快捷记账**：可选择启动时直接进入记账界面
- **记录管理**：支持编辑和删除已有记录
- **本地数据与备份**：账本和聊天记录保存在本机 SQLite；「我的」可导出包含账本、账单、重复记账、设置、AI 聊天及账单照片的密码保护备份，并与本机数据合并恢复。备份包含已保存的 AI API Key，请妥善保管密码和文件；Android 系统自动备份已关闭。旧 ZIP/JSON 可继续导入；旧 JSON 不含照片文件
- **AI 助手**：支持用户自填服务 URL 与 API Key，点击获取 OpenAI 兼容模型列表后下拉选择并保存；新配置不预设 URL 或模型，已有有效 MiniMax 配置保留。AI 助手页支持本地发起的 MiniMax / OpenAI 兼容流式文本对话；当服务端返回普通 JSON 时也会自动按非流式结果处理；支持展示并本地保存模型返回的思考过程（可折叠，默认收起，思考不回传给模型）；当前已支持本地 SQLite 持久化多会话、会话切换、新建与重命名。可选的 AI 账单操作支持当前账本内的查询及单条账单新增、修改、删除（含转账账单），查询、读取选项和本页上下文复用自动进行；新增、修改和删除在最终内容明确后显示原生预览，用户确认一次才执行。账本和资产管理工具仍未实现。

## 🛠️ 技术栈

- **开发语言**：Kotlin
- **最低 SDK**：Android 7.0 (API 24)
- **目标 / 编译 SDK**：Android 14 (API 34)
- **UI 框架**：XML 布局 + Material Components + Fragment
- **数据层**：SQLite（`DatabaseHelper.kt`）
- **网络层**：OkHttp（用于 MiniMax BYOK 文本聊天）
- **构建工具**：Android Gradle Plugin 8.3.0 + Gradle Wrapper 8.13

### 验证入口

Windows 可使用带阶段超时和失败清理的统一验证脚本：

```powershell
.\scripts\run-android-verification.ps1
```

该脚本由开发者手动按需运行，不会随每次代码修改自动触发。运行后会串行执行 Debug 编译、JVM 单测，预编译隔离设备测试 APK 后按 14 组逐组验证；每组最多 60 秒。全部 147 项完成且通过才报告 PASS，失败或超时会保留分组日志。

可按需要缩小运行范围：

```powershell
# 仅运行 JVM 单测
.\scripts\run-android-verification.ps1 -SkipDebugBuild -SkipDeviceTests

# 只运行指定设备组（示例：分类数据库组）
.\scripts\run-android-verification.ps1 -SkipDebugBuild -SkipUnitTests -DeviceGroups category-db

# 只构建日常 Debug APK
.\scripts\run-android-verification.ps1 -SkipUnitTests -SkipDeviceTests
```

`-DeviceGroups` 可接收一个或多个 `scripts/verification-device-groups.ps1` 中的组名；未指定时运行全部设备组。

## 📦 安装步骤

### 1. 克隆仓库

```bash
git clone https://github.com/zhiwk/CardTally.git
cd CardTally
```

### 2. 构建项目

```bash
# Windows (PowerShell)
.\gradlew.bat assembleDebug

# Windows release (signed when keystore.properties is available)
.\gradlew.bat :app:assembleEverydayRelease

# Mac/Linux
./gradlew assembleDebug
```

### 3. 安装应用

将生成的 APK 文件安装到 Android 设备：

```
app/build/outputs/apk/debug/app-debug.apk
```

## 🚀 使用指南

### 快速记账
1. 打开应用，点击右下角的「+」按钮进入记账页面
2. 在极简录入页中选择收支类型（收入/支出）并输入金额
3. 在页内选择叶子分类；日期和资产通过底部选择器设置。支出、收入的资产可以“不选择”，账单仍保存并计入统计，但不影响资产余额；未配置默认资产时默认不选择。转账必须选择不同的转出、转入账户
4. 标准模式按一级分类展开，快速模式直接平铺叶子分类
5. 添加备注（可选）后，点击底部「保存」完成记账

也可在资产账户详情页点击「转账」进入转账录入，当前账户自动作为转出方；选择另一个转入账户、填写金额及可选手续费后保存，返回详情页会更新余额和流水。转账记录保存到当前账本。

### 查看账单与统计
1. 「账单」页默认显示当前账本、本月统计和当月明细；右滑查看上个月，左滑查看下个月，顶部账本栏固定，统计与明细一起翻页
2. 进入「统计」页查看分类、周期和趋势图表；左右翻页或点击顶部切换支出／收入，图表与排行榜一起移动，选中横线跟随翻页过渡
3. 账单明细可按日期浏览记录，并继续编辑或删除记录

### 管理分类
1. 进入「设置」页面
2. 点击「分类管理」
3. 切换支出/收入标签页
4. 点击「添加分类」创建新分类，或编辑/删除现有分类

### 快捷记账设置
1. 进入「设置」页面
2. 打开「是否快捷记账」开关
3. 下次启动应用将直接进入记账界面

### 配置 AI 助理
1. 进入「我的」页面
2. 在「AI 助理」分组中打开「显示 AI 入口」开关
3. 点击「API 配置」进入二级页面，依次填写服务 URL（基础地址或完整对话地址）与 API Key，点击「测试并获取模型」，从下拉列表选中模型并保存；模型列表查询不发送对话，也不验证每个模型的对话权限。服务需提供 OpenAI 兼容的模型列表接口
4. 进入「AI 助手」页后，左上角菜单可切换历史会话，长按会话可重命名；右上角 `+` 可新建会话，默认命名为“新会话-年月日”
5. 模型回复会在支持流式返回时增量显示；若接口返回普通 JSON，则会自动回退为一次性展示完整回复
6. 当前会话与消息会保存在本地 SQLite 中，切换页面或重启应用后仍会保留，并自动恢复上次活动会话
7. 会话列表展开时，底部导航会随 AI 助手页面临时隐藏，关闭抽屉后恢复显示
8. 关闭该开关后，底部「AI 助手」标签会隐藏
9. 若需要让 AI 协助操作账单，在「API 配置」开启「允许 AI 提出账单操作」（默认关闭）；所选服务和模型需要支持 OpenAI 兼容的工具调用。开启后 AI 自动查询当前账本的账单、账户和分类，并将结果及本页对话上下文发送给所配置服务；可一次提出多个查询，本机依次执行；混合或多个写入建议会自动要求模型单独重提一条完整建议。缺少信息时在聊天中询问。最终新增、修改或删除直接打开预览，核对账本、账单内容和余额影响后点击一次「确认执行」；回复“确认”等文本不会写入
10. 本机回执会记录已完成的操作，即使模型随后回复失败也不会自动重复执行。页面退出后待确认操作作废；同一页面继续使用前轮上下文无需再次确认；每轮最多成功写入一条，操作其他账单需新请求。操作日志可在「API 配置」查看或清除，日志仅保存在本机，目前不随完整备份导出；聊天中的账单工具消息参与聊天备份，但不会进入普通聊天请求

### 一级页与二级页导航规则
1. 账单 / 统计 / 资产 / AI 助手 / 我的 属于一级页，显示底部导航
2. 进入二级页面（如记一笔、编辑记录、外观、API 配置等）后，底部导航会隐藏
3. 返回一级页后，底部导航会恢复显示
4. 在 AI 助手页展开会话抽屉时，底部导航也会临时隐藏，关闭抽屉后恢复

### 编辑/删除记录
1. 在账本明细中找到要操作的记录
2. 点击记录进入「账单详情」页，查看详情和附件；底部「编辑」进入与「记一笔」共用的录入界面，并跟随「我的 → 记一笔模式」选择
3. 修改金额、日期、资产、分类或备注后保存；支出、收入可在资产选择器点击“不选择”清除原关联，保存时撤回旧资产的余额影响
4. 如需删除，在详情页点击「删除」并确认；账单、日历、搜索、统计明细和资产流水均使用详情入口，账单条目不再提供左划操作

### 重复记账
1. 从账本页进入「重复记账」并新建或编辑任务
2. 选择账本、类型、周期、开始时间和可选结束时间
3. 转账类型需要分别选择转出资产和转入资产，两个资产不能相同
4. 任务账本只决定任务数据与资产选择范围，不会切换应用当前账本
5. 到期任务由本地调度处理；每月 31 日和每年 2 月 29 日在目标日期不存在时跳过该次执行

## 🎨 当前视觉

外观页按纯色背景、图片背景分成两张卡片，两类均可选择浅色、深色或跟随系统，默认纯色浅色。两套调色板共用页面结构和语义资源；深色使用深灰背景、稍亮卡片和清晰的文字与收支颜色，品牌图标保留原色。在外观页点击「添加图片」可通过系统选择器导入图片，成功后加入本机图片库并自动启用图片背景。三张内置的「默认图片 1、2、3」、已有自选图和后续添加的图片以可横向滑动的缩略图陈列，点击即可切换，当前图片显示选中标记；三张默认图片均不可删除，只有自选图片右上角「×」可直接删除，删除当前自选图后回到默认图片 1；「恢复默认图片」只切换到默认图片 1，不删除图库图片。导入文件不超过 32MB，缩小大图后保存到应用本地，按屏幕比例居中裁切，可单独选择浅色、深色或跟随系统配色（已有用户默认深色），对应使用浅色或深色遮罩与卡片；中性页面卡片默认 80% 不透明，可通过滑杆以 5% 步长调整到 0%–100%，松手后应用并保存，切换图片配色沿用滑杆当前数值，不分别记忆。文字和图标保持清晰，弹窗和底部导航使用所选配色的实底。图片库及当前图片选择暂不包含在备份中，恢复到没有自选背景的应用时使用内置图片。具体视觉约束以根目录 `DESIGN.md` 为准。
