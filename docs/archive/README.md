# `docs/archive` 说明

本目录存放 **历史执行计划、一次性实现方案、阶段性工作草案**。

这些文档可以帮助理解当时为什么这样规划、有哪些实现思路、曾经拆过哪些任务，但它们**不是当前仓库事实的最高权威来源**。

## 使用规则

当这里的内容与其他来源冲突时，默认按以下顺序判断：

1. 当前源码与 Gradle 配置
2. `AGENTS.md`
3. `docs/requirements/decisions/*.md`
4. `docs/requirements/plans/*.md`
5. 本目录文档

## 适合来这里找什么

- 某次页面重构的具体拆解方式
- 某个阶段的实施节奏与任务颗粒度
- 历史方案里的备选设计或执行路径

## 不适合直接拿这里做什么

- 不要把这里的页面结构当成“当前已实现”
- 不要把这里的业务规则表述当成最终规则
- 不要跳过源码验证直接照搬
