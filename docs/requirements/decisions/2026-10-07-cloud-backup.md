# WebDAV 加密云备份与恢复

## 用户确认的范围

云备份与恢复，不做多设备实时同步。2026-10-26 用户因尚未验证 S3，要求移除该存储类型，当前仅提供 WebDAV；此项取代早期同时支持 WebDAV/S3 的范围。手动备份加可选每日自动备份，新配置默认勾选本机加密保存备份密码与每日自动备份，确认保存有效配置后才加密存储并安排任务；已有 WebDAV 配置保留原选择。旧非 WebDAV 自动目标停用，不自动切换连接，页面自动备份保持未勾选直至用户重新确认保存。自动备份仅 Wi-Fi，不提供限速。自动历史保留数量可设置，默认 15 份，范围 1–365；手动备份不自动清理。完整备份包含自选背景图库与选择状态。

## 实现与安全边界

- 「我的 → 云备份」独立二级页，配置 WebDAV 连接、测试读写、保存、立即备份、列举、预检恢复、确认合并与确认删除。不再提供存储类型选择、桶、区域、令牌或路径式寻址字段。确认保存仅写入 WebDAV 配置，替换旧本机云连接和废弃凭据；断开清除所有本机云连接及保存的密码，保留远端文件。
- 旧加密配置不静默改写或当作 WebDAV 使用。UI 仅加载旧 WebDAV 表单；旧非 WebDAV 活跃目标在打开页面时取消任务，Worker 在构建网络客户端前也检查并取消任务、返回空配置，即使另存了 WebDAV 也不自动启用。移除前保存的视图状态不作为新表单凭据恢复，必须重新读取 WebDAV 配置；新版表单重建继续遵守原密码不保存到视图状态的规则。旧凭据留在原加密文件内，直到用户确认保存新配置或断开后清除，不删除任何远端对象。
- 只支持 HTTPS，系统证书验证且不自动跟随重定向。WebDAV 使用 Basic / 应用专用密码、PROPFIND Depth 1、MKCOL、GET、HEAD、PUT、MOVE、DELETE。需要服务支持防覆盖创建：随机临时文件 MOVE 到目标并使用 Overwrite: F；连接测试验证第二次创建被拒绝且原文件内容不变，不遵守即停止。不宣称所有服务商兼容。S3 签名器、请求/分页分支及专用测试源码已移除，备份格式、加密及 WebDAV 防覆盖语义不变。
- 备份仍包含财务数据、账单照片、设置、AI 聊天和已保存的 AI API Key；页面和保存确认说明范围。连接凭据、云任务状态、设备命名空间与云备份密码不进入备份。
- 云配置文件位于 noBackupFilesDir，Android Keystore AES-GCM 保护。备份密码至少 8 位；手动可不保存密码，自动要求用户勾选保存。本机密码和连接配置不是云端找回途径，忘记备份密码不能恢复。更换已建立空间的密码需使用新目录，不原地重新加密历史。
- 云目录按 dev/release 分隔。vault.json 保存随机盐及密码验证值；PBKDF2-HMAC-SHA1 200000 次派生 256 位密钥，文件压缩后 AES-GCM 加密并绑定格式 AAD。随机 nonce 独立于文件内容，文件名使用密钥 HMAC 的原始内容标识，不暴露明文照片哈希。
- 每次保存完整数据快照，照片和背景分文件增量上传，同一安装实例的历史共享相同内容文件。为避免跨设备清理竞争，设备命名空间独立，不跨设备去重；备份来源映射仍保留既有跨设备合并规则。
- 初次或新增对象上传后读回并验证；后续复用已完成加密清单中的已验证对象，正常备份不会下载旧图片。自动内容指纹相同则跳过新快照，仍可重试历史清理。重试可复用已完整上传的文件；无引用的中断对象可修复。不实现单文件分段续传或上传限速。
- 最后发布唯一命名的加密 snapshot 清单作为完成标记，未完成对象不出现在备份历史。清单也压缩后加密，清理复用本次已验证清单，减少重复下载。列表显示时间、自动/手动、随机设备标识片段和当前对象大小总计（不含服务端回收站）；传输显示新增上传估算及实际上传/下载字节数。新对象读回验证会增加下载流量，不能把上传估算当全部流量。
- 使用 WorkManager 日周期和网络 CONNECTED 条件，再在开始与每次网络读写检查实际 Wi-Fi transport 和有效连接，避免把“不限流量”误当 Wi-Fi。离开 Wi-Fi 后中断并退避重试，不承诺固定时间；错误凭据/密码需要用户修正。长任务仍受 Android 后台调度限制，首次大量数据建议手动前台备份。
- 新备份确认成功后，仅清理当前设备、当前渠道超过保留数量的自动清单；之后只删除同设备已无任何保留清单引用的对象。手动清单及其他设备保留。若清理失败，已完成备份有效，页面报告清理未完成。删除其他设备清单不自动清理其图片，防止与该设备上传竞争。
- 恢复下载、验证并重建私有 ZIP，先调用原有回滚式预检；确认后使用同一个已验证本机缓存合并，不重复下载图片。已有条目和资产余额冲突沿用原决策，删除不传播。正式数据库合并开始后不提供取消按钮；取消下载不会发起合并。
- 本机缓存可能暂存完整 ZIP、压缩附件及已验证恢复包，需要足够空间。每个操作结束清理工作目录，恢复缓存由页面 ViewModel 清理；进程被终止留下的超过一天缓存在下次操作时清理。清单、文件和累计展开大小均有上限，沿用财务备份的总体限制。

## 备份格式兼容

本地完整 ZIP 版本从 2 扩展为 3，新增 wallpapers 条目和 selectedWallpaper；加密容器仍沿用原 CTB3。本版本仍接受 v2 ZIP 及旧 JSON，旧应用不能恢复新 v3 格式。默认三张图片只保存选择 ID，不复制打包资源。自选图库按内容合并，同内容恢复不重复创建，已有图库和选择不覆盖；未设置主题且无自选图的初始状态采用备份选择。数据库和系统文件不能组成单一事务，数据库提交后若图库写入失败应报告失败，重试利用既有身份映射避免重复账单。

## 验证状态

2026-10-26：移除 S3 专用签名器及其2项测试源码，新增5项配置JVM测试源码，覆盖旧WebDAV兼容、序列化不再携带S3字段、拒绝非WebDAV类型及旧活跃目标不回退休眠WebDAV。未构建、执行测试、安装或访问任何远端服务，也未读取本机实际云凭据或推送GitHub。此前文件加密/篡改/去重标识及历史保留隔离用例继续保留，测试状态不因移除而视为通过。

后续经用户明确要求验证时，先执行相关 Debug 单测；数据库、背景恢复和任务隔离验证只在 verification 变体；再使用用户指定服务测试首次备份、无变化跳过、新增图片增量、Wi-Fi 中断、恢复不重复下载、错误密码、配置切换与 15 份历史清理。

WebDAV 随机临时上传文件在 MOVE 完成时由服务端移除，失败/取消时尽力删除；进程终止或断网可能留下临时文件，不作为有效备份，不批量删除其他操作的暂存文件。错误提示仅显示操作方法和 HTTP 状态，不包含 URL、凭据或响应正文。

协议参考：[WebDAV](https://www.rfc-editor.org/info/rfc4918/)、[Android 网络约束](https://developer.android.com/reference/androidx/work/NetworkType)。

## 坚果云目标已存在响应兼容

用户真机反馈 MOVE HTTP 409。KeePass2Android 项目原始问题及后续修复记录指出，坚果云向已存在目标执行移动会返回 409。CardTally 不采用该项目针对替换文件的「删除目标后移动」做法：当前只做禁止覆盖创建，仅在连接主机严格为 dav.jianguoyun.com、MOVE 返回 409 且对确切目标 HEAD 成功时，视为目标已存在并返回未创建。连接测试仍读回原文件核对哈希不变；目标不存在或探测失败不视为防覆盖成功，保留具体错误。暂存文件按原规则清理，不删除原目标；其他 WebDAV 服务行为不变。

依据：[KeePass2Android 原始问题与服务兼容记录](https://github.com/PhilippC/keepass2android/issues/3010)。截图尚不能证明 409 是首次移动还是第二次测试；该兼容分支需真实服务再次测试，未读取用户凭据或执行云端请求。

## 2026-11-17 WebDAV 配置二维码

用户确认以未加密二维码分享完整 WebDAV 连接，并支持相机、图片导入；另允许勾选携带备份加密密码。此项是独立、显式授权的配置转移入口，不改变“财务备份不包含云凭据或云备份密码”的边界。

- 分享当前表单的 HTTPS 地址、用户名、登录密码、备份目录；不直接复用 `CloudConfig.json()`，不携带自动备份、保留数量、设备标识或财务数据。独立 `cardtally-webdav:` 前缀加 version=1 的平面 JSON，只识别本应用格式，UTF-8 总长最多 2000 字节。
- 「同时分享备份加密密码」每次打开默认关闭。生成前必须确认二维码未加密及凭据暴露风险；勾选后额外明确“拿到二维码的人可能下载并解密财务备份”。展示和系统 PNG 分享均保留风险说明，不把二维码当加密或访问授权隔离。
- 编解码使用本机 ZXing，不调用在线二维码服务。相机仅在用户选择扫码时请求 CAMERA，拒绝后可改用系统图片选择器，不申请存储权限。相机只识别 QR，关闭声音和拍摄图片保存；截图/最近任务中的二维码、预览和相机窗口使用 FLAG_SECURE。
- 相机结果通过进程内一次性 token 交接，待返回 Intent 只有 token，不携带原始密码；60 秒后 token 不再有效，进程死亡则丢弃结果，需重新扫描。表单密码仍不保存到视图状态；未确认的二维码内容不写云配置或财务备份，不输出到日志或错误消息。
- 仅点击「分享图片」后写入私有 `cache/webdav_qr/` PNG，通过既有 FileProvider 的专用窄路径仅授予所选接收方读取。为兼容异步分享接收方，不立即删除；下次进入云备份页或导出图片时清理本目录超过一小时的 PNG，不承诺一小时后定时删除，也无法撤回接收方已经复制的图片。
- 图片输入最多 16MB、原始最多 6400 万像素，采样到最长边不超过 2048；支持常规与反色二维码，后台解码，离页取消任务并忽略过期回调。解码前限制载荷长度，逐项读取平面 JSON 字段，不递归解析嵌套对象/数组，并拒绝重复键；严格校验字段白名单、类型、版本、HTTPS、凭据、目录及可选备份密码最短 8 位。地址和目录规则与手动输入/CloudStore 共用。
- 导入先展示地址、用户名、目录及密码是否携带，密码始终遮挡。确认仅替换未保存表单：未携带备份密码时清空旧值，表单保存密码/自动备份取消勾选，保留数量不变，旧连接的列表和恢复预检缓存清除。不会调用保存/调度/网络/恢复；已保存配置和现有任务保持不变，测试、保存与原有确认仍需用户手动操作。取消、无效码及不支持的版本不改表单。
- 增加 `WebDavQrCodecTest` 11 项 JVM 测试源码，覆盖白名单/默认不带备份密码、显式密码/Unicode 往返、字段归一化、格式版本/类型/嵌套拒绝、HTTPS/目录共用规则、空凭据/短密码、UTF-8 边界、对象字符串脱敏及实际 QR 编解码往返。未运行构建、测试、安装、真机扫码或分享验证；真实相机、图库及系统分享兼容性仍未验证。
