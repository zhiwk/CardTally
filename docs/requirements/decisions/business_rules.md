## 1. 删除记录资产处理（Q1-A1）

### 规则
删除支出记录时，自动将对应金额加回资产余额，无需用户二次确认。

### 代码逻辑
```kotlin
// DatabaseHelper.kt
/**
 * 删除记录并自动更新资产（基于规则 Q1-A1）
 * @warning 支出删除会立即回滚资产，无需确认
 */
fun deleteRecord(record: Record) {
    if (record.type == EXPENSE) {
        assetBalance += record.amount // 自动回滚资产
    }
    database.delete(record.id)
}
```

### 测试用例
```kotlin
fun testDeleteExpenseRefundsAsset() {
    val initialBalance = getAssetBalance()
    addExpenseRecord(100.0)
    deleteLastRecord()
    assertBalance(initialBalance) // 应等于初始值
}

fun testDeleteIdempotency() {
    deleteRecord(recordId)
    deleteRecord(recordId) // 第二次删除应无资产变动
    assertAssetUnchanged()
}
```

### 影响范围
- `DatabaseHelper.kt` - 删除逻辑
- `AssetFragment.kt` - 需监听记录删除事件并刷新资产显示

## 2. 分类统计规则（Q2-A2）

### 规则
每条记录只绑定叶子分类 ID。分类统计先按 ID 汇总，不能因同名叶子分类而合并；默认排名分别展示叶子分类。用户切换一级分类视图时，界面可以把其下叶子分类汇总展示，但不改变记录的分类绑定，也不改变叶子分类的独立统计结果。

同名叶子分类分别显示并按分类 ID 进入对应明细；一级视图的金额等于其下叶子分类金额之和。

### 影响范围
- `StatisticsFragment.kt` - 分类统计计算
- `DatabaseHelper.kt` - 查询逻辑

## 9. 转账手续费

> 创建时间：2026-09-12

### 规则
- 手续费仅对转账记录有效；支出与收入记录的手续费恒为 0，即使传入也会被忽略。
- 转账余额语义：转出资产扣「金额 + 手续费」，转入资产只加「金额」；差额即为手续费。
- 删除转账记录时与新增完全对称：转出资产加回「金额 + 手续费」，转入资产扣回「金额」。
- 手续费计入支出总额与支出趋势（月度），但不进入分类统计（转账/手续费没有分类）。
- 手续费允许为空（视为 0），不允许为负数；使用与金额相同的输入语法与校验。

### 影响范围
- `DatabaseHelper.kt`：`records.fee` 列（v30 迁移）、`createRecordValues`、`createRecordFromCursor`、`createRecordDeletionUndoValues`、`applyRecordAssetEffect`、`getTotalByType` / `getTotalByTypeAndDateRange` / `getMonthlyStatistics`。
- `model/Record.kt`：`fee` 字段。
- `AddRecordFragment.kt` 与两种录入布局：转出/转入整行大卡 + 手续费入口，复用金额键盘并在金额↔手续费之间切换目标。
- `state/RecordFormState.kt`：`feeBuffer` 草稿字段。
- 记录列表：转账行金额下方显示「含手续费」。

## 7. 账本与资产关系（Q5-C1）

> 2026-09-11补充：以下关于新建入口和合并范围的旧描述，已由 `2026-09-11-ledger-asset-groups.md` 更新：新建直接选择独立组或现有组；仅同组账本可合并；分类保持全局，不迁移分类。其余保护规则继续有效。补充需求尚待实施。

### 规则
- 资产通过不可变资产 ID 绑定记录，不通过名称绑定。
- 默认账本始终拥有主资产池，主资产池永久存在；所有新建账本默认共用主资产池。
- 新建账本关闭“共用主资产”后，才可选择独立资产池，或共用其他账本的完整资产集合；只有主资产账本时不显示“共用其他账本”。
- 共用资产共享余额和资产所有权，非所有者账本不可编辑、置顶、归档或删除该资产。
- 复制资产生成新的资产 ID，初始余额复制当时的余额，后续余额和操作完全独立。
- 合并账本必须二次确认；记录、分类和资产迁移至当前账本，源账本删除，资产 ID 与历史记录保持不变。
- 主资产所属账本不可被删除或作为合并来源，以保证主资产池始终存在。

## 8. 全局分类

### 规则
- 分类是应用级唯一数据集，不隶属于账本、资产或其他业务对象。
- 新建账本不会复制或创建分类；所有账本使用同一份一级、二级分类树。
- 记录只能选择叶子分类；分类的父子关系、排序和图标在全局范围内生效。
- 从旧版本升级时，按“收支类型 + 父分类 + 名称”合并重复分类，并将记录引用迁移到保留的分类 ID。

## 10. 收支资产可选

2026-10-04 用户要求新增、编辑收支账单可使用“不选择”资产。无关联时保存空资产 ID/名称，不改变任何资产余额，仍计入账单及分类统计；清除已有关联时由原更新事务撤回旧余额影响。转账继续要求不同的转出/转入账户。默认资产、类型记忆、选择器宿主及 AI 参数规则见 `2026-10-04-optional-record-assets.md`。
