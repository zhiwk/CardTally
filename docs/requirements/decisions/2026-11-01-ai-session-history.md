# 账本会话与历史上下文

状态：用户确认，源码已调整；未执行构建、测试或真实服务验证。

本决策取代 2026-10-04-ai-record-tools.md 中仅复用本页内存、切换 API 不复用及工具文本不进入普通聊天的限制，其他工具注册、单条写入及原生确认规则不变。

- 会话固定归属账本，只展示当前账本会话；未归属旧会话以明确标记展示，选择存活账本后才可继续，不推断过去的财务归属。绑定仅一次，不复制历史到所有账本。
- 重新打开、重启、切换会话后再返回，发送时自动从该会话持久消息构建文本上下文；仅打开不联网。切换 API 服务、Key 或模型后继续发送历史，包含财务查询内容；配置页说明此边界。关闭工具只禁止新工具调用，不禁止同会话历史文本发送。
- 只携带相同会话的有效 user/assistant 文本，不携带推理、错误或未完成回复，不拼接其他会话。最多保留近期80条、48000字符（包括当前输入，超长输入拒绝），不截断单条文本，去掉裁减后开头的无对应用户消息的回答。工具请求另有 system 消息与本轮工具结果，不将字符预算宣称为模型 token 容量保证。
- 不持久化或重放可执行工具链、确认状态或旧操作权限。历史回执只是背景，模型需重查当前数据再提出基于历史的写入，执行仍重新校验与原生确认。退出页面、配置变化或切换范围取消待确认操作；请求回调按会话与账本核对。
- SQLite v45新增可空会话ledger_id，旧会话保持未归属；新会话绑定当前账本。账本删除或合并移除来源账本后，其会话保留为待归属，不自动混入保留账本。
- 完整/云备份ZIP v5重映射会话账本ID；兼容v2/v3/v4与旧JSON，无归属保留为空。旧应用不能恢复v5，恢复历史不执行财务操作。
