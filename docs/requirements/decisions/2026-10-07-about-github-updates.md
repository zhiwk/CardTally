# 关于页与 GitHub 更新

用户要求在当前应用增加关于页，手动检查 GitHub 正式 Release，确认后下载并更新。仓库 `zhiwk/CardTally` 已公开，用户已正式发布 `v0.0.2`；本轮源码默认版本推进为 `0.0.3 / 3`，构建与安装仍需另外授权。

- 我的 → 关于为独立二级页面，展示应用名称、实际构建版本和 dev/release 渠道；沿用共享返回标题、页面与卡片主题色。
- 只在点击检查时请求公开 `/releases/latest`，不上传财务数据、不保存 GitHub 凭据、不自动轮询。仅接受稳定 X.Y.Z 标签，用数值比较；草稿与预发布不参与。
- release 优先下载 `cardtally-X.Y.Z.apk`；dev 优先下载 `cardtally-dev-X.Y.Z.apk`，兼容历史 `XiaomaoJizhang` 对应渠道名称。缺少当前渠道包时提示并提供发布页面入口，不跨包安装。当前 0.0.2 仅有 release 包；后续发布如需支持 dev 更新，须附对应包，并保持其原签名。
- 发现更新后，由原生弹窗确认下载版本和大小。展示进度并允许取消；旋转保留状态，不重复发起下载或自动安装。离开关于页销毁对应 ViewModel 时取消未完成请求。
- 下载仅使用 HTTPS GitHub 及其指定资产域名，安装包限制 100 MiB。接受 GitHub 资产 SHA-256 digest，缺少时读取同一 Release 的 SHA256SUMS.txt；无有效校验值时停止。
- 下载到应用私有缓存，校验长度、SHA-256、当前包名、发布版本名称、严格递增 versionCode、设备最低系统要求及相同当前签名证书。签名轮换暂不支持；校验失败不打开安装器。临时失败文件删除，成功缓存可重试安装，超过一天的旧缓存在下一次下载时清理。
- 用户点击安装后交由系统安装器确认，Android 8+ 未授权时说明并打开安装权限设置，授权返回后继续安装。取消安装保留当前应用与数据；不卸载、不读取其他渠道数据、不静默安装。
- 新页面与协议测试仅静态复核；未获得构建或测试授权时不执行相应命令。
