# 收支账单可不选择资产

状态：用户已授权；源码已实施并静态复核，dev 已构建并覆盖安装。尚未运行测试或验证无资产新增/编辑及余额行为。

后续选择器样式调整已实施并随最新 dev 构建、覆盖安装；尚未运行测试或进行真机页面验证。不选择项改为与资产条目共用布局的卡片，置于页面标题之后、首个资产分类之前，不另设分类标题。

依据：用户要求新增、编辑记账条目时资产可不选择，并提供默认的“不选择”。

## 行为

- 支出、收入录入页以“不选择”显示空资产；资产选择器置顶提供可点击的不选择项，无资产时显示选中标记。没有配置默认资产时，新录入保持不选择；用户已明确设置的收支默认资产继续生效，编辑已有记录保留原值。
- 点击不选择只清除当前记录、当前类型的资产。类型切换、页面重建和“再记”保留该空选择，不因已配置默认账户而重新选回；不修改全局默认资产偏好。
- 未关联资产的账单依旧参与收支、分类及日期统计，新增、删除不改变资产余额。编辑由有资产改为无资产时，原写入事务先撤回旧资产的余额影响，再保存无资产记录；从无资产改为有资产时正常计入所选资产。
- 转账仍必须选择不同的转出、转入账户，不提供不选择项。共享底部选择器通过默认关闭的 `allowNoAsset` 参数控制入口；普通收支宿主启用，重复记账及默认资产设置宿主不启用，原回调契约保留。
- 不选择通过选择器回调的 `NO_ASSET_ID = 0` 表达清空，宿主转换为 `assetId = null`、`assetSource = null`；不创建名为“不选择”的资产，也不把占位名称或 0 写入账单资产列。
- AI 账单工具同步允许无资产收支：新增省略或传 `asset_id: null`；修改省略保留原关联，传 null 清除原关联；转账仍要求非空账户 ID。最终预览明确显示不选择及实际余额影响。

## 实现与验证边界

已有模型、表及余额事务支持空资产，继续复用，不新增数据库迁移。新增和编辑共用 `AddRecordFragment`。不选择项在 `AssetFragment` 的列表滚动区域复用 `item_asset`，不显示类型或余额，空选择时显示选中底色及勾选标记。沿用资产分组卡片的圆角、行内间距及主题颜色，深浅色共用布局；未开启 `allowNoAsset` 的宿主不显示该卡片。
