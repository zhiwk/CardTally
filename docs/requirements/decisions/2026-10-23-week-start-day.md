# 一周起始日设置

用户要求在「我的」增加“一周起始日”，只提供周日和周一，点选即保存。

- 默认周一，保持既有行为；不按语言自动改变。
- 应用于日历列头与日期排列、记账/重复记账日期选择器、统计“周”的日期边界和搜索“本周”范围及日期选择器。
- 月/年/自定义范围、已有记录日期和重复任务执行星期编号不受影响；任务中固定的周一至周日含义不能因展示偏好改变。
- 使用 `cardtally_preferences/week_start_day` 保存 Calendar 的周日/周一值；无效值回退周一。设置纳入既有完整/云备份偏好白名单。
- 与现有圆角菜单样式一致，选中勾选，取消不保存。已有统计页面在恢复可见时更新周边界，保留所浏览周的中点。

新增4项JVM测试源码覆盖合法值、列头顺序、周日边界、跨年周及月历对齐；本轮未运行测试或构建，实际页面效果仍需验证。
