# 账本资产组与同组合并

状态：用户已确认需求，待实施及验证；不代表当前源码已经满足。

## 已确认规则

- 一个账本使用一组账本资产，多个账本可以引用同一组；共享的是相同资产ID及余额，不是资产副本。记录仍有唯一所属账本。
- 新建账本可新建一组独立账本资产，或从现有资产组中选择一组。现有组按稳定组身份去重，不按使用它的账本重复列出；新建独立组不复制其他组的资产或余额。
- 账本/资产管理页支持将同组的两个账本合并为一个。不同组的账本不能通过此入口合并。必须明确保留目标并二次确认；取消无写入，成功后源账本移除、记录归入目标。不重复记账、复制资产或叠加共享余额。
- 同一资产的详情显示所有账本引用该资产ID的记录，包括转入和转出。金额下方右侧显示每条记录所属账本的名称，不是当前账本名称或资产名称。

## 与既有决策的关系

本决策更新 business_rules.md 第7节：新建入口以“新建独立资产组 / 选择现有资产组”表达，不再强制先关闭“共用主资产”才能选择；合并限定同组，不再迁移或复制全局分类。第8节全局分类规则继续有效。

未被本次需求改变的规则继续保留：主资产组永久存在、主账本不能作为合并来源；资产管理权限不因跨账本查看而扩大；编辑账本仅编辑名称和图标。默认仍选择现有主资产组，但必须直接可见并可切换为独立组，不隐藏选择。若合并包含主账本，它只能作为保留目标。

不新增组重命名、跨组合并、复制资产、合并撤销或AI操作。组身份可沿现有资产池根映射实现，不强制重建表结构；若需要迁移必须单独说明且保留所有ID、余额和历史。

详细交互、原子性、第三方共享引用与验收见 OpenSpec ux-consistency-handoff 的 ledger-asset-groups.md 和 specs/ledger-asset-groups/spec.md。
