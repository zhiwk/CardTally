# AI 账本与资产工具范围

状态：产品所有者已确认范围；尚待设计、实施与验证。

决策日期：2026-09-26

2026-10-04 补充：账单记录的增删改查已由用户另行授权，适用 [AI 账单工具决策](2026-10-04-ai-record-tools.md)。本文件针对账本/资产管理的既有范围与保护规则继续有效，下文对记录工具的排除由新决策限定取代。

决策依据：用户明确要求继续 `openspec/changes/ai-ledger-asset-tools`，并选择完整账本/资产 CRUD、允许余额校准及二次确认、允许账本级联删除及精确预览、逐请求财务数据授权和本地可清除审计。

## 1. 能力范围

- Provider 计划支持多模型；新配置不预设 URL 与模型，以 [API 配置与模型发现决策](2026-10-04-api-model-discovery.md) 为准；保留现有有效 MiniMax 配置，不静默迁移或覆盖 API Key、模型和 URL。
- 财务工具覆盖用户授权范围内的账本和资产查询、新建、修改、归档/恢复与删除；以稳定 ID 定位实体，任意账本访问必须经领域规则校验，不受当前界面选中值影响。
- 不提供账单记录、分类、转账、预算或统计的直接 AI 工具；删除账本时按第 4 节发生的级联记录删除是唯一例外。
- 不允许模型执行 SQL、代码或未注册工具；普通文本、伪造按钮和“好的/确认”等自然语言永远不是写入授权。

## 2. 财务数据外发授权

- 财务工具默认关闭。普通 BYOK 文本聊天与财务工具授权分离。
- 每个将包含财务字段的 Provider 请求，在发送前必须显示本次将发送的字段类别和目标 Provider，并取得用户逐请求授权。拒绝或取消时不得读取/序列化额外财务字段，也不得调用财务工具。
- 仅发送完成本次用户请求所需的最少字段；不得预载全量账本或资产。API Key、Authorization、隐藏推理和设备信息不得进入工具结果或审计。
- 更换 Provider、模型或协议时，待确认写操作立即失效；Provider 私有续接字段不得跨 Provider 发送。

## 3. 写入确认与余额校准

- 每项写入先生成只读预览，展示目标稳定 ID、当前值、拟变更、影响范围和过期状态，再由聊天中的原生确认卡片授权执行。每轮最多一个待确认写入，操作幂等且过期后不可执行。
- 允许直接校准资产余额，但必须标记为“余额校准”，显示旧值、新值、差额和共享资产影响，并在同一卡片完成二次确认。
- 余额校准只修改资产余额及对应本地审计，不自动新建、修改或删除账单记录；界面不得声称差额已有账单解释。

## 4. 删除和共享资产保护

- 账本删除允许级联删除其所属账本的记录。预览必须从当前数据库计算并显示记录删除数量、涉及资产池/共享引用变化、受影响账本和当前账本回退目标；用户二次确认后才可事务执行。
- 主账本不可删除，不能删除全部账本。共享资产池根被删除时必须保留存活账本可用的资产及稳定 ID，并按现行规则重新指定存活所有者；失败时所有更改回滚。
- 资产永久删除仅限已归档且没有任何记录或仍有效删除撤销记录引用的资产，并须显示精确影响、二次确认。引用检查必须覆盖来源和转入资产 ID；历史兼容名称字段也须受保护，直到迁移/兼容策略证明不会误删。
- 资产管理权限、叶子分类约束、金额精度和资产组规则继续有效。AI 不得借改组、复制资产或切换当前账本绕过限制。

## 5. 本地审计

- 写入建议、用户确认/拒绝/取消、过期、成功和失败均在本机 SQLite 审计；包含必要的会话/操作标识、Provider/模型、工具名、目标、影响摘要、快照指纹、终态和时间，不记录 API Key、认证头或隐藏推理。
- 用户必须能从应用内查看对应操作结果，并拥有显式清除本地 AI 财务审计的入口。清除审计不得修改账本、资产或聊天之外的财务数据。
- 不将审计上传，不宣称其具备监管或审计合规能力。

## 6. 与当前代码的差异和实施门槛

- 当前实现仍只有 MiniMax 文本聊天；本决策授权的是未来能力，不代表功能已经存在。
- 当前资产读写由 `AssetWriteRepository` 按当前账本作用域限制；账本详情更新也要求目标为当前账本。实施时须抽取可复用服务，在保留 UI 约束的同时安全支持稳定 ID 目标。
- 当前资产删除回调 `assetNameIsReferenced` 只检查记录与尚未过期撤销项的来源名称，未覆盖转入资产引用，也未以双端稳定 ID 完整判定。AI 永久删除不能直接依赖该检查；须实现完整引用核查与迁移/兼容测试。
- 当前账本删除规则位于 `LedgerWriteRepository.deleteLedgers`：禁止删除主账本或全部账本，会删除目标账本记录，并为存活共享池成员保留/重指资产；当前账本回退由 `LedgerManagementFragment` 在事务成功后设置。AI 服务应复用同一事务语义并在成功后执行等价回退，不得由模型猜测影响。
- 上述实现差异须通过领域服务和隔离数据测试关闭；不得以改变当前业务限制或仅增加提示文案替代。

## 7. 取代关系

本决策仅取代 `2026-08-12-light-ux-redesign.md` 第 4 节关于未来 AI 操作必须另行决策的等待状态，以及 `AGENTS.md` 中 AI 仅文本聊天的未来能力限制；它不改变第 3 节 AI 概览的数据白名单，不授权 AI 概览读取账本/资产，也不授权记录、分类、转账、预算等独立写操作。当前代码事实仍以已实施源码为准。
