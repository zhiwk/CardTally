# 图片背景外观

> 决策日期：2026-10-05
> 状态：用户要求新增图片外观；已实施和静态复核，未构建或进行设备验证

在「我的 → 外观」保留浅色、深色、跟随系统，新增「图片背景」单选及图片预览。初始版本使用用户提供的图片作为内置背景；用户随后授权支持选择本机图片，扩展如下。

模式值为现有 `theme_prefs/theme_mode` 的 3，默认值仍为浅色 0。沿用设置持久化、完整备份的整数偏好契约及页面状态恢复；初始图片外观没有新增偏好键，后续图片配色新增整数键，详见末尾，无数据库迁移。图片模式默认使用深色配色，现支持用户单独选择浅色或深色；切换外观保存后重建页面，由 `MainActivity` 在加载布局前应用配色与样式，使普通和图片模式之间的切换也能立即生效。

背景在 Activity 内容区域固定显示，使用 `centerCrop` 按屏幕比例居中裁切，不随列表或月份滚动。页面画布通过 `pageBackgroundColor` 变为透明，初始深色版叠加 `#C0121416` 中性深色遮罩；后续浅色版对应使用浅色遮罩，详见末尾。背景为装饰，不参与点击和辅助功能遍历；普通模式不加载全屏背景图片。

用户继续要求可调节：外观页增加「卡片不透明度」滑杆及百分比，0%–100%、5% 步长，默认 80%。仅图片模式启用；手指松开后重建应用，键盘或辅助功能调节在短暂停顿后应用，离开页面取消待执行回调。数值以 `theme_prefs/card_opacity` 整数保存，非法类型回退 80%，越界值限于 0–100 并归整到步长。完整备份白名单与旧格式整数恢复同步支持此键，无数据库迁移。Activity 在布局加载前应用仅覆盖 `cardSurfaceColor` 的不透明度样式，保证 XML、共享底图和运行时卡片填色一致；其他外观不应用该覆盖。未新增模糊或整卡 alpha。

## 账单页日期组不透明度叠加修复

用户截图报告月统计卡片和账单卡片不透明度不一致。源码确认 `item_date_group` 父卡片已使用 `cardSurfaceColor`，嵌套 `LedgerDateGroupAdapter.DayRecordAdapter` 仍调用条目绑定绘制相同半透明底色，造成两层叠加（例如 50% 叠加后为 75%），而月统计只有一层。

为共享条目绑定增加默认关闭的 `parentProvidesBackground` 参数，日期组内开启后普通条目底色透明，只由父卡片绘制；独立列表保持原有自身底色，选中高亮仍保留，每次绑定重新设置背景，防止复用串用。日期组父卡片显式透明前景，和月统计一致，不增加遮罩层。不改变不透明度偏好、主题、文字/图标 alpha、业务数据或查询；本轮仅静态复核，未编译、运行测试或安装。
