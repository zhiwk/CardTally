# L10n Design

**Goal:** 为 CardTally 建立最小可用的国际化基础设施，暂时支持中文和英文，并允许用户在“我的”页立即切换语言。

## 方案

- 使用 AndroidX `AppCompatDelegate.setApplicationLocales` 作为应用级 locale 入口。
- 在 `SettingsFragment` 新增语言设置项，展示当前语言并允许切换为 `中文` 或 `English`。
- 新增 `LanguageHelper` 统一封装语言读取、设置和展示文案。
- 以字符串资源为主：新增 `values-zh-rCN/strings.xml` 与 `values-en/strings.xml`。

## 范围

- 底部导航
- “我的”页与语言切换入口
- “记一笔 / 编辑记录”共享录入页
- 首页关键标题
- Agent 页输入提示
- 常见 Toast、主题名称等高可见文案

## 兼容策略

- 先覆盖核心高可见文案，避免一次性清理全仓库所有硬编码字符串。
- 日期格式从强制中文改为跟随当前 app locale。
- 不改数据库存储内容，不引入业务规则变更。
