# CardTally 首版范围冻结文档

## 1. 文档目的

本文档用于冻结 CardTally 首版范围，明确以下边界：

- 首版必须成立的基础产品能力
- 首版可选的 Agent 增强能力
- 首版明确不做的内容
- 后续所有 UX、视觉与开发工作的判断依据

本文档的核心目标，是防止产品在设计和实现阶段不断扩张，或被 Agent 能力带偏主结构。

## 2. 首版总原则

CardTally 首版必须先作为一个独立成立的优秀记账软件存在。

这意味着：

- 即使没有 Agent，产品也必须完整、好用、好看
- Agent 是增强层，不是产品成立前提
- 任何核心链路都必须存在非 Agent 路径
- Agent 的价值是提高体验上限，而不是填补基础产品缺陷

## 3. 首版产品定义

首版产品定义为：

一个本身就优秀的、设计驱动的财务陪伴型记账产品，Agent 作为增强协作层存在。

这里的优先级顺序是：

1. 先把基础记账产品做成立
2. 再让 Agent 为体验加分

而不是：

1. 先依赖 Agent 建立核心流程
2. 再补基础产品能力

## 4. 首版信息架构范围

首版信息架构一级能力区域固定为：

1. 首页
2. 记录
3. 记一笔
4. 资产
5. Agent
6. 我的

说明：

- 这是信息架构层级，不代表 UI 上必须一一对应独立导航按钮
- “记一笔”仍然是一级能力，但入口形态后续可再定
- Agent 是一级能力，但不是基础产品主链路的唯一入口

## 5. 首版必须成立的基础产品能力

以下能力属于首版必须成立的基础产品能力，即使完全不启用 Agent，也必须顺畅可用。

### 5.1 基础记账主链路

必须成立：

- 用户可直接新增一条记录
- 用户可查看历史记录
- 用户可编辑已有记录
- 用户可完成基础记录管理

### 5.2 首页基础能力

必须成立：

- 首页可作为产品主入口
- 首页可提供轻量财务概览
- 首页可承接高频动作导流

### 5.3 资产基础能力

必须成立：

- 用户可查看资产总览
- 用户可进入基础资产管理入口
- 资产页可提供独立于记录页的财务状态视角

### 5.4 我的基础能力

必须成立：

- 用户可进入低频设置与偏好区域
- 主题、分类相关等低频能力可被收纳

## 6. 首版 Agent 增强能力

以下能力属于 Agent 增强层。它们重要，但不能成为基础产品成立的前提。

### 6.1 首版建议纳入的 Agent 能力

建议纳入：

- Agent 独立入口
- Agent 基础会话空间
- Agent 对财务信息的轻量提醒或总结
- Agent 对用户的辅助解释或建议

### 6.2 首版可存在但不能强依赖的 Agent 能力

可以存在，但不能绑死主链路：

- Agent 辅助生成记录建议
- Agent 帮助补全分类、备注或解释
- Agent 输出待确认事项

要求是：

- 用户始终可以绕过 Agent 直接完成操作
- 用户不用 Agent 时，不应感觉产品残缺

## 7. 首版明确不做的内容

以下内容首版明确不做，或不作为本轮重点：

- 独立统计一级页面
- 重图表的数据可视化体系
- 复杂多层设置体系
- 过度主题定制能力
- 全量旧页面同步翻新
- 完整复杂的 Agent 自动记账工作流
- 让 Agent 成为唯一记账入口
- 让 Agent 成为唯一查询或解释入口

## 8. 范围判断标准

后续所有设计和实现判断，都应优先通过以下问题：

1. 这项能力是否有助于基础记账产品先成立？
2. 这项能力是否强化了设计驱动的整体气质？
3. 这项能力是否会让核心路径更简单，而不是更复杂？
4. 这项能力是否把 Agent 放在“增强层”，而不是“依赖层”？
5. 这项能力是否真的值得进入首版？

如果不能通过这些判断，应优先考虑延后。

## 9. 首版成功标准

首版是否成功，不取决于 Agent 做了多少复杂事情，而取决于以下两点是否同时成立：

### 9.1 基础产品成立

- 不用 Agent，用户依然能顺畅完成记账、查账、看资产、做基础设置
- 页面结构清晰
- 视觉质量成立
- 产品气质稳定

### 9.2 Agent 作为增强层成立

- 用户能感知到 Agent 的存在价值
- Agent 能提供辅助、提醒、解释或陪伴
- Agent 不会破坏基础产品的清晰度

## 10. 结论

CardTally 首版必须先是一个优秀的记账软件，再是一个带 Agent 的财务陪伴产品。

因此首版范围冻结结论是：

- 基础产品优先于 Agent
- Agent 是增强层，不是依赖层
- 核心记账链路必须存在非 Agent 路径
- 所有超出上述边界的内容，应默认延后
