# CardTally 账单页 UX 设计讨论稿

> 状态：讨论中
>
> 范围：账单页的页面结构、信息层级、月份浏览、账单列表和交互反馈。
>
> 说明：本文是账单页独立设计稿，不代表其他一级页面必须复制账单页的内容结构。

## 1. 设计目标

账单页是 CardTally 的核心一级页面，主要任务是让用户快速完成三件事：

1. 知道当前查看的是哪个账本和月份。
2. 快速理解当月收入、支出和结余。
3. 按日期浏览、添加和修改账单。

账单页不承担趋势分析、复杂报表或资产管理功能。趋势和分类分析进入统计页。

## 2. 页面边界

账单页属于一级页面标准页面，但只作为页面骨架和交互规范的参考实现。

一级页面统一由两部分组成：

```text
页面内容
底部菜单栏
```

账单页的顶部栏属于页面内容的一部分，可以随页面内容滚动。底部菜单栏固定在屏幕底部。

## 3. 当前已确认方向

### 3.1 页面背景与表面

- 页面底色为浅灰色。
- 有意义的内容分组使用白色卡片承载。
- 账单记录行保持普通白色行，不单独做成卡片。
- 卡片使用细描边和轻微阴影，不使用装饰性渐变。

### 3.2 顶部栏

顶部栏从左到右包含：

```text
账本图标 + 账本文本 + 切换提示图标       搜索图标 + 日历图标
```

- 不显示月份文本。
- 搜索和日历只显示图标。
- 账本名称可以点击切换账本。
- 日历用于精确选择月份。
- 顶部栏属于滚动内容，不固定在页面顶部。

### 3.3 本月统计

统计卡片位于顶部栏下方，显示：

```text
月份统计标题
收入        支出        结余
```

标题规则：

- 当前月份：`本月统计`
- 同一年其他月份：`9月统计`
- 其他年份：`2024年3月`

统计卡片本身可以点击，用于选择或切换月份。

统计卡片采用紧凑型布局：

- 上内边距：`8dp`。
- 下内边距：`8dp`。
- 左右内边距：暂定 `16dp`。
- 标题与指标区间距：`6dp`。
- 指标标签与金额间距：`4dp`。
- 指标之间不额外增加大间距，保持三列紧凑对齐。
- 卡片不设置固定高度，使用 `wrap_content`，目标视觉高度约 `104dp~112dp`。
- 金额和标签保持清晰，不通过压缩字号换取紧凑布局。
- 统计金额保持单行显示；当金额超过指标列宽时，使用横向循环播放，不换行。

### 3.4 账单明细

账单按日期分组，每天作为一个独立分组：

```text
日期                         当日合计
--------------------------------------
账单行
账单行
账单行
```

- 日期与合计是普通文本，不做成单独卡片。
- 每日账单列表使用一个分组容器。
- 账单行显示分类图标、分类名称、备注/辅助信息、金额和时间。
- 金额右对齐，收入和支出使用正负号及语义颜色共同表达。
- 不再额外显示“明细”标题行。

### 3.5 添加账单

- 使用图标型 FAB。
- 不显示“记一笔”文字。
- FAB 不遮挡底部菜单或最后一条账单。

### 3.6 底部菜单

底部菜单使用普通全宽栏，不使用浮动卡片样式：

- 紧贴屏幕底部。
- 左下角和右下角为直角。
- 文字距离屏幕底部约 `5dp`。
- 图标和文字之间使用紧凑间距，目标值为 `0dp` 或 `2dp`。
- 每一项保留至少 `48dp` 触控区域。
- 菜单栏固定，不随账单内容滚动。

## 4. 月份浏览交互

已废弃通过账单页顶部/底部继续上拉或下拉切换月份的方案。账单内容滚动只负责浏览当前月份，不再触发月份切换。

当前保留两种明确入口：

- 统计卡片左侧按钮：切换上个月。
- 统计卡片右侧按钮：切换下个月。
- 点击统计卡片其他区域：打开年份和月份双列表选择弹窗。

空月份与有记录月份使用相同的月份入口，不依赖内容高度或边界手势。

## 5. 空状态

建议空月份显示：

```text
本月暂无账单
```

空状态不再套一层卡片，也不显示复杂插画。

是否显示月份切换提示，待月份交互方案确定后再决定。

## 6. 动效方向

- 顶部栏随内容自然滚动。
- 月份按钮切换使用短距离纵向位移动画和透明度过渡。
- 拉动距离越接近 `200dp`，目标月份提示越清晰。
- 月份切换使用短距离纵向位移动画和透明度过渡。
- 账单列表不使用逐行入场动画。
- 用户开启减少动画时，只保留状态和透明度变化。

## 7. 暂不讨论内容

本轮账单页 UX 讨论暂不包含：

- 统计页图表布局。
- 资产页结构。
- 分类管理页结构。
- AI 助手页面。
- 数据库字段和账单核算规则。
- 主题切换和深色模式。

## 8. 下一步讨论顺序

建议按以下顺序确认：

1. 账单页首屏的信息层级和卡片高度。
2. 每日账单分组和账单行的具体字段。
3. 空月份的展示内容。
4. 年份/月双列表弹窗的视觉细节和滚轮高度。
5. 确认后再转换为 XML 布局和 Material 样式资源。
