# 资产银行图标

银行选择页按用户 2026-10-03 提供的截图清单，展示常用银行与字母分组；银行名称是本地目录中的标识名称，不表示银行卡发卡资格或联网查询结果。

图标随应用离线打包，保留品牌原色。SVG 标识转换为 Android VectorDrawable，未在运行时下载图标。

- 矢量图标来源：[IconGo bank-logos](https://github.com/icongo/bank-logos)，MIT 许可全文随应用存放于 `app/src/main/assets/licenses/bank-logos-MIT.txt`。
- 安徽农信、江苏农信、嘉兴、内蒙古、成都农商五个 PNG 标识来源：[bank.logo](https://github.com/burningmyself/bank/tree/master/bank.logo/resource/logo)，保留原始资源字节。品牌商标属于相应银行。
- “其他银行”采用本项目绘制的通用账户图标。
