## 快速开始

### 1. 先读品牌指南
`brand-design-guide.md` 确立：
- 产品定位：静奢理财日记
- 用户感受目标
- 设计关键词和禁区
- 竞品氛围参考

### 2. 再读视觉指南
`visual-design-guide.md` 定义：
- 色彩系统的感知方向（不给具体色值，让 Stitch 生成）
- 字体层级的建议范围
- 间距系统的节奏建议
- 组件设计的风格方向

### 3. 最后看页面指南
`page-design-guide.md` 明确：
- 6 个一级页面的具体布局结构
- 每个页面的推荐和禁止出现内容
- 统一的通用设计规范
- 完整的设计输出清单

## 核心设计原则

```
静奢理财日记
    │
    ├── 静：安静、不喧嚣、无压迫感
    │
    ├── 奢：高级感、品质感、讲究细节
    │
    ├── 素：克制、留白、纯净
    │
    └── 暖：有温度、陪伴感、亲切
```

---

## 设计禁区提醒

生成设计时请**始终避免**：

1. 高饱和度的主色调
2. 数据密集的 dashboard 风格
3. 模板化的常见记账 App 外观
4. 过度卡通或可爱的元素
5. 拥挤的信息布局
6. 粗重的分割线和阴影

---

## 产品信息架构

```
CardTally 6 个一级能力区域
│
├── 首页 (Home)      - 陪伴感 + 轻量概览
├── 记录 (Records)   - 历史账目管理
├── 记一笔 (Add)     - 高频录入（页面内入口）
├── 资产 (Assets)    - 账户与余额状态
├── Agent           - 协作助手
└── 我的 (Me)       - 低频能力收纳
```

**注意**: "记一笔"不做底部导航 tab，通过首页/记录页的按钮进入。

---

## 输出格式建议

生成的 UI 设计建议输出为：

1. **Figma 可编辑文件** 或
2. **高清 PNG/PDF 展示图**

每个页面建议包含：
- 默认状态
- 空状态（如果有）
- 加载状态（如果适用）
- 交互状态（如键盘展开）
