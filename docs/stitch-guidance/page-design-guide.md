# CardTally 页面设计指南 (For Stitch)

## 1. 概述

本文档为 Stitch 提供每个一级页面的具体设计指导，确保生成的 UI 符合产品定位。

**产品气质**: 静奢理财日记
**核心感受**: 安静、高级、陪伴感、有温度

---

## 2. 首页 (Home)

### 2.1 页面角色
- 产品的情绪入口
- 提供陪伴感和连续使用感
- 轻量但有方向感的财务概览
- 回答"我现在怎么样"、"最近值得注意什么"

### 2.2 视觉氛围
- 像一本打开的私人日记首页
- 留白慷慨，信息不过密
- 带有轻量的财务信息，但不显得像 dashboard
- 可以有日期感、时光流逝感的视觉暗示

### 2.3 推荐布局结构

```
┌─────────────────────────────────┐
│     [日期/时间] 轻量的时间感      │
│                                 │
│  ┌─────────────────────────┐    │
│  │   本月概览卡片           │    │
│  │   收入: 柔和的正向色      │    │
│  │   支出: 柔和的负向色      │    │
│  │   余额: 清晰但不刺眼      │    │
│  └─────────────────────────┘    │
│                                 │
│  ┌─────────────────────────┐    │
│  │   最近值得注意的记录      │    │
│  │   (2-3条精选，不超过5条)  │    │
│  └─────────────────────────┘    │
│                                 │
│  ┌─────────────────────────┐    │
│  │   记一笔 按钮 (主入口)    │    │
│  └─────────────────────────┘    │
│                                 │
│     [底部导航区域]              │
└─────────────────────────────────┘
```

### 2.4 首页禁止出现
- 复杂的统计图表
- 大面积的数据面板
- 过多的数字和百分比
- 密集的记录列表

### 2.5 首页设计关键词
- 日记感、陪伴感、平静、留白、轻量
- 月份/日期的仪式感
- 精选内容而非全量展示

## 3. 记录页 (Records)

### 3.1 页面角色
- 完整历史账目浏览
- 查找、筛选、管理账目
- 功能型页面，但保持优雅

### 3.2 视觉氛围
- 清晰、有序、可信赖
- 记录条目有呼吸感
- 分组感清晰（日/周/月）

### 3.3 推荐布局结构

```
┌─────────────────────────────────┐
│     记录         [搜索] [筛选]  │
│                                 │
│  ┌─────────────────────────┐    │
│  │ 3月27日                  │    │
│  │ ├─ 早餐    -25   餐饮     │    │
│  │ ├─ 地铁    -5    交通     │    │
│  │ └─ ...                   │    │
│  └─────────────────────────┘    │
│                                 │
│  ┌─────────────────────────┐    │
│  │ 3月26日                  │    │
│  │ ├─ 工资   +8000  收入    │    │
│  │ └─ ...                   │    │
│  └─────────────────────────┘    │
│                                 │
│  [记一笔 浮动入口]               │
│                                 │
│     [底部导航区域]              │
└─────────────────────────────────┘
```

### 3.4 记录页禁止出现
- 每屏超过 7-8 条记录（显得拥挤）
- 过多的筛选选项同时显示
- 使用粗重的分隔线

### 3.5 记录页设计关键词
- 清晰、可管理、有秩序
- 时间分组感
- 轻量的分类/金额标签

## 4. 记一笔 (Add Record)

### 4.1 页面角色
- 高频录入入口
- 最快速度完成记录
- 低阻力、高确定性

### 4.2 视觉氛围
- 简洁、专注、不混乱
- 金额输入是视觉焦点
- 分类选择直观但不抢焦点

### 4.3 推荐布局结构

```
┌─────────────────────────────────┐
│  ← 记一笔           [取消]      │
│                                 │
│         ¥ 0.00                 │
│      (大号字体，视觉焦点)         │
│                                 │
│  ┌─────────────────────────┐    │
│  │  [支出]    [收入]         │    │
│  └─────────────────────────┘    │
│                                 │
│  分类 ─────────────────────     │
│  [图标] 餐饮  [图标] 交通 ...    │
│                                 │
│  日期 ─────────────────────     │
│  今天，3月27日  周四            │
│                                 │
│  备注 ─────────────────────     │
│  [点击添加备注...]              │
│                                 │
│  ┌─────────────────────────┐    │
│  │      保存记录             │    │
│  └─────────────────────────┘    │
└─────────────────────────────────┘
```

### 4.4 记一笔禁止出现
- 过多的输入字段（超过 4-5 个）
- 复杂的键盘切换
- 弹窗式的二级确认

### 4.5 记一笔设计关键词
- 专注、简洁、低阻力
- 金额最大最突出
- 一两步完成

## 5. 资产页 (Assets)

- 账户与余额状态展示
- 超越单笔的财务结构视角

- 秩序感、私密感

- 秩序感、私密感、品质感

- 数字优雅可读

## 6. Agent 页

### 6.1 页面角色
- 独立助手角色入口
- 协作、提醒、解释、建议
- 主动陪伴层

### 6.2 视觉氛围
- 有温度的对话感
- 像与一位贴心的财务助手交流
- 建议和提醒温和、不压迫

- 过度技术感的对话界面

- 有温度、陪伴、贴心
- 温和的建议而非命令
- 对话感而非工具感

## 8. 通用设计规范

### 8.1 导航栏
- 底部导航 5 个 tab：首页、记录、资产、Agent、我的
- "记一笔"不放在底部导航，通过页面内按钮进入
- 导航图标：线性风格，24-28dp

### 8.2 状态栏与沉浸感
- 页面顶部状态栏应与页面背景协调
- 追求沉浸式的视觉体验

### 8.3 字体层级统一
- 页面标题：22-24pt
- 区块标题：18-20pt
- 正文：15-16pt
- 辅助文字：13-14pt

### 8.4 颜色应用统一
- 主色调：柔和的深色系
- 背景：多层次暖色调
- 收入/正向：柔和暖绿/米色
- 支出/负向：柔和灰棕/旧玫瑰
- 强调色：哑光金/玫瑰金点缀

### 8.5 圆角统一
- 卡片：16-24dp
- 按钮：12-16dp 或全圆角
- 输入框：8-12dp
- 小元素：4-8dp

## 9. 设计输出清单

请为以下每个界面生成完整设计：

1. **首页** - 默认状态（含概览卡片、最近记录）
2. **首页** - 空状态（无记录时）
3. **记录页** - 默认状态（含记录列表）
4. **记录页** - 搜索/筛选展开状态
5. **记一笔** - 默认状态（支出）
6. **记一笔** - 切换到收入状态
7. **记一笔** - 键盘展开状态
8. **资产页** - 默认状态（含资产列表）
9. **资产页** - 新增资产弹窗
10. **Agent页** - 默认状态（欢迎界面）
11. **Agent页** - 对话中状态
12. **我的页** - 默认状态
