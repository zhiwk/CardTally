# CardTally 视觉设计指南 (For Stitch)

## 1. 设计目标

为 CardTally 生成符合"静奢理财日记"气质的现代化 UI 界面。
设计应传达：安静、高级、克制、有温度、有品质感。

---

## 2. 色彩系统设计指导

### 2.1 主色调方向
**建议策略**: 偏向柔和的深色调或温暖的中性色

- **首选方向**: 柔和的深紫灰色系、或温暖的米色/棕色调
- **次选方向**: 低饱和度的墨绿色、深蓝色
- **避免方向**: 明亮的主色调（如正蓝、正紫、亮红）

### 2.2 背景色层次
产品应有多层次的背景质感，而非纯平背景

| 层次 | 视觉感受 | 建议 |
|------|---------|------|
| 最底层 | 纸张质感底色 | 微微暖色调的浅灰/米白 |
| 中间层 | 卡片/容器层 | 略深的暖灰/奶油白 |
| 顶层 | 悬浮元素 | 最浅，带微妙阴影 |

### 2.3 语义色彩使用

#### 收入/正向
- 使用柔和的暖色调
- 避免刺眼的亮绿或亮金色
- 建议：柔和的橄榄绿、暖米色系

#### 支出/负向
- 使用低饱和度的柔和色调
- 避免红色警告感
- 建议：柔和的灰棕色、旧玫瑰色

#### 强调/高亮
- 少量使用，作为视觉点缀
- 建议：哑光的金色、柔和的玫瑰金

### 2.4 色彩禁区
- 不使用 #FF5722 (橙红) 作为警示色
- 不使用 #4CAF50 (正绿) 作为成功色
- 不使用 #2196F3 (正蓝) 作为主色
- 不使用高饱和度的任何颜色

## 3. 排版系统设计指导

### 3.1 字体选择方向

**标题字体**
- 推荐：无衬线字体，但带有优雅的字形特征
- 参考感觉：高端杂志标题、有品质感的品牌字体
- 避免：过于几何化的字体（显得工具感）

**正文字体**
- 推荐：清晰易读、略带温度的无衬线字体
- 参考感觉：设计精美的出版物的正文字体

**数字字体**
- 推荐：等宽或带有设计感的数字字体
- 重要：数字应看起来有品质感，不是计算器数字

### 3.2 字体层级建议

| 层级 | 字号感觉 | 行高建议 | 字间距建议 |
|------|---------|---------|-----------|
| 大标题 | 28-32pt | 1.3-1.4 | 略宽松 |
| 页面标题 | 22-24pt | 1.3 | 正常 |
| 卡片标题 | 18-20pt | 1.4 | 正常 |
| 正文 | 15-16pt | 1.6 | 正常 |
| 辅助文字 | 13-14pt | 1.5 | 略宽松 |
| 标签/小字 | 11-12pt | 1.4 | 正常 |

### 3.3 排版禁区
- 不要使用衬线字体（显得过时）
- 不要使用过于花哨的装饰字体
- 不要让行高过紧（压迫感）
- 不要让文字颜色与背景对比过强

---

## 4. 间距系统设计指导

### 4.1 留白原则
**核心原则**: "呼吸感"比"填满"更重要

- 页面边距建议偏大（至少 24dp，建议 32dp）
- 卡片内部留白应慷慨（16-24dp）
- 元素之间保持足够的垂直间距
- 同类元素之间的距离应小于不同类元素

### 4.2 间距节奏建议

| 场景 | 建议范围 |
|------|---------|
| 页面水平边距 | 24-32dp |
| 页面垂直边距 | 16-24dp |
| 卡片内边距 | 16-24dp |
| 卡片间距 | 16-20dp |
| 同类元素间距 | 8-12dp |
| 不同类元素间距 | 20-32dp |
| 大区块之间 | 40-60dp |

### 4.3 间距禁区
- 不要让元素贴近页面边缘
- 不要让卡片紧密排列（像列表）
- 不要让信息挤在一起

---

## 5. 卡片与容器设计指导

### 5.1 卡片设计方向

**整体感觉**: 轻盈、有质感、像优质的纸张卡片

| 属性 | 建议 |
|------|------|
| 圆角 | 16-24dp（柔和但不过度） |
| 阴影 | 极轻的阴影，柔和边缘 |
| 边框 | 可选微妙细线（不是必须） |
| 背景 | 略暖的白色或浅灰 |

### 5.2 容器层级建议

产品应有清晰的层级感，但不是靠粗重的分割线：

1. **底层背景**: 微微暖色的底色
2. **内容容器**: 轻阴影的卡片
3. **悬浮元素**: 更轻的阴影，可略带圆角

### 5.3 卡片禁区
- 不要使用生硬的黑色阴影
- 不要使用过度圆角（显得幼稚）
- 不要使用粗边框来区分层级
- 不要让卡片看起来像塑料材质

---

## 6. 图标设计指导

### 6.1 图标风格方向

**推荐风格**: 线性图标 + 柔和线宽

| 属性 | 建议 |
|------|------|
| 类型 | 线性图标（不是填充型） |
| 线宽 | 1.5-2dp（精致但清晰） |
| 圆角 | 线条末端略带圆角 |
| 整体感觉 | 优雅、精致、不厚重 |

### 6.2 图标尺寸建议

| 场景 | 尺寸建议 |
|------|---------|
| 底部导航图标 | 24-28dp |
| 页面内功能图标 | 20-24dp |
| 内联小图标 | 16-20dp |
| 空状态插画 | 自定义尺寸，略大 |

### 6.3 图标禁区
- 不要使用过于卡通的图标
- 不要使用过粗的线条
- 不要使用填充型图标作为主图标
- 不要混用不同的图标风格

---

## 7. 组件设计指导

### 7.1 按钮设计方向

**主按钮**
- 风格：柔和填充，哑光质感
- 圆角：全圆角（pill 形状）或大半径（12-16dp）
- 阴影：几乎无阴影或极轻阴影
- 颜色：低饱和度，不刺眼

**次按钮**
- 风格：幽灵按钮（描边）或轻填充
- 圆角：与主按钮一致
- 颜色：与主色同色系但更淡

**文字按钮**
- 用于低优先级操作
- 颜色：柔和的中性色

### 7.2 输入框设计方向

- 圆角：中等（8-12dp）
- 边框：细线（1dp），低对比度
- 聚焦状态：柔和的高亮显示（不是粗边框）
- 背景：温暖的浅色

### 7.3 列表项设计方向

- 卡片式列表（而非纯线条分割）
- 每项之间保持适当间距
- 点击反馈：柔和的背景色变化
- 支持滑动操作时，滑动动画应流畅

### 7.4 组件禁区
- 不要使用尖锐的直角按钮
- 不要使用高对比度的输入框边框
- 不要使用粗分割线来组织列表
- 不要让按钮看起来像 2015 年的 Material Design

---

## 8. 导航设计指导

### 8.1 底部导航方向

**整体风格**: 简洁、优雅、克制

| 属性 | 建议 |
|------|------|
| 图标风格 | 线性，细线条 |
| 标签 | 简短，优雅 |
| 激活状态 | 柔和的颜色变化（不是粗重高亮） |
| 背景 | 微妙阴影或纯色 |
| 高度 | 偏矮（56-64dp），留出更多内容空间 |

### 8.2 导航交互

- 切换动画：流畅、不过度
- 当前页面指示：柔和的视觉变化
- 图标与标签的激活状态应一致

### 8.3 导航禁区
- 不要使用过于卡通的图标
- 不要在底部导航使用过多颜色
- 不要让底部导航显得厚重

---

## 9. 特殊界面设计指导

### 9.1 空状态设计

**原则**: 优雅、有温度、给出方向感

- 使用简约的插画（线条风格）
- 文字友好、温暖
- 给出明确的行动指引

### 9.2 加载状态设计

**原则**: 柔和、不焦虑

- 使用优雅的加载动画
- 避免使用旋转的粗线条
- 加载过程不应显得急促

### 9.3 错误状态设计

**原则**: 温和、帮助性、不吓人

- 使用柔和的颜色表达错误
- 文字应友好而非责备
- 给出明确的解决方向

---

## 10. 整体视觉输出要求

生成完整 UI 时应保证：

### 一致性
- 所有页面使用统一的视觉语言
- 颜色、字体、间距、圆角在所有页面保持一致
- 相同功能的元素在各处表现一致

### 完整性
- 覆盖 6 个一级页面：首页、记录、记一笔、资产、Agent、我的
- 每个页面包含主要状态：默认/空/加载/错误
- 包含常用的组件设计（按钮、输入框、卡片、列表项）

### 可用性
- 高频操作（如记一笔）路径简短
- 重要信息一目了然
- 交互反馈清晰但不喧宾夺主
