# CardTally 首页设计规格 (V1)

> 本文档记录首页设计决策，供 Stitch 出图使用。

---

## 产品定位

**整体气质**：静奢理财日记
**角色定位**：陪伴感首页，回答"我现在怎么样"、"最近值得注意什么"
**语言风格**：干练精明，财务主管/管家风格

---

## 首页模块清单

| 模块 | 说明 | 优先级 |
|------|------|--------|
| 顶部日期 | 3月27日  周四 | P0 |
| 本月概览卡片 | 收入 + 支出 + 余额 | P0 |
| 最近记录 | 3条精选，点击进入编辑页 | P0 |
| 记一笔入口 | FAB 悬浮按钮 | P0 |
| Agent 入口卡片 | 首页卡片，名片/字条风格 | P0 |
| 空状态 | 方案二 + 管家风格文案 | P0 |

---

## 模块详细规格

### 1. 顶部日期
- 格式：3月27日  周四
- 位置：页面顶部左侧或居中
- 字体：优雅，偏大

### 2. 本月概览卡片
- 内容：收入、支出、余额三个数字
- 收入：柔和正向色（暖绿/米色）
- 支出：柔和负向色（灰棕/旧玫瑰）
- 余额：清晰主色
- 布局：可三行并排，或卡片内三列

### 3. 最近记录
- 数量：3条精选
- 点击行为：跳转到编辑记录页
- 布局：轻量列表，不拥挤
- 每条显示：分类图标 + 金额 + 简要备注

### 4. 记一笔入口
- 形态：FAB 悬浮按钮
- 位置：右下角
- 图标：+ 号或羽毛笔
- 颜色：柔和主色，不刺眼

### 5. Agent 入口卡片
- 风格：名片或字条风格
- 位置：首页内，概览与记录之间或底部
- 文案风格：管家口吻，干练精明
- 示例文案：
  - "账本已就位，随时待命。"
  - "静候您的第一笔记入。"
  - "记录每一笔，理清财务。"

### 6. 空状态
- 风格：方案二（日记欢迎型）
- 插画：简约羽毛笔插画
- 文案：管家/财务主管风格，干练精明
- 按钮：开始记账 / 记下第一笔

---

## 首页明确不出现的内容

- 月份切换（不需要）
- 复杂统计图表
- 周/月/年筛选按钮
- 资产快捷入口（走底部导航）
- 搜索框
- 过长的记录列表

## 底部导航

首页不放置底部导航（由 MainActivity 统一处理）

---

## 设计关键词

安静、高级、克制、有温度
干练、精明、管家感

---

## 设计禁区

- 不使用高饱和度颜色
- 不使用卡通元素
- 不使用粗重分割线
- 不做数据密集型展示
